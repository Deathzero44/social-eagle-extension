# 社媒采集到 Eagle

一个 Manifest V3 Chromium 扩展，可把小红书、Instagram 和 X 帖子的图片、视频、正文与原帖网址保存到 Eagle。

## 项目结构

| 文件 | 用途 |
| --- | --- |
| `manifest.json` | 扩展入口、权限与站点匹配规则 |
| `background.js` | Eagle API 通信、下载回退与扩展消息处理 |
| `content.js` | 小红书帖子识别与导入按钮 |
| `instagram-content.js` | Instagram 帖子识别、按钮与导入流程 |
| `instagram-media.js` | Instagram 页面媒体数据读取 |
| `x-content.js` | X 推文识别、按钮与媒体采集 |
| `popup.html`、`popup.css`、`popup.js` | Eagle Token、标签和文件夹设置 |
| `icons/` | 各站点使用的 Eagle 图标 |

项目不需要构建步骤；在浏览器扩展管理页直接加载本文件夹即可。

## 安装

1. 在 Eagle 中启用本地 API，并复制 API Token。
2. 在 Edge 或 Chrome 打开扩展管理页，启用“开发人员模式”。
3. 选择“加载解压缩的扩展”，选中本项目文件夹。
4. 点击扩展图标，填写 Eagle Token 并保存设置。
5. 打开小红书或 Instagram 帖子，或 X 信息流；帖子媒体左上角会常驻显示 Eagle 图标。X 的导入图标显示在帖子顶部操作区的 Grok 图标旁边。

已有安装的更新：在 `edge://extensions` 或 `chrome://extensions` 找到本扩展并点击“重新加载”，如浏览器提示新增网站访问权限请允许，然后刷新目标页面。

扩展连接 `http://localhost:41595`。Eagle 必须正在本机运行并启用本地 API。

## Instagram

- 信息流、帖子详情和 Reels 的媒体容器左上角常驻显示 Eagle 图标，不需要悬停；图标放在页面最上层的独立覆盖层，避免被 Instagram 视频播放器盖住。
- 点击后先从页面已加载的 JSON 中按当前帖子的短码或媒体 ID 读取完整数据；缺少数据时再请求媒体信息和 GraphQL 接口。图片与视频按原帖顺序编号，视频选择返回版本中分辨率最高的地址。
- 只使用当前帖子返回的媒体地址，不从其他帖子收集图片。已确认媒体清单中的某项视频或图片失败时，其余项目继续导入，并显示失败项编号和部分成功数量；无法确认完整图集清单时会停止并说明原因。
- 普通视频、混合图集中的视频和 Reels 共用导入流程：先让 Eagle 按链接导入；Eagle 明确拒绝时，扩展临时下载视频再通过本地文件接口导入，随后清理临时文件。视频任务不会阻塞图片队列。
- Eagle 的 `website` 字段保存标准帖子网址，`annotation` 字段保存帖子正文。作者与正文首行用于生成 Eagle 项目名称；可在设置中把正文里的 `#话题` 和作者加为标签。视频下载或导入失败时，错误原因会显示在图标旁。
- 需要在 Instagram 登录状态下使用。帖子数据接口由 Instagram 页面提供，接口调整、登录失效或限流时可能无法读取；此时图集不会退化成只导入一张图。

## X

- 信息流和帖子页面中，有图片或视频的帖子会在顶部 Grok 图标左侧显示 Eagle 图标，使用 `icons/eagle-x.svg` 中的原始颜色，不透明度为 50%，尺寸为 Grok SVG 的 90%。
- 点击后按当前推文 ID 读取帖子数据，优先收集原推文的全部照片与最高码率 MP4；原推文没有媒体时再检查引用或转帖内容。图像只按 `pbs.twimg.com` 图片 CDN 地址导入，视频只按 `video.twimg.com` 的 MP4 地址导入。
- Eagle 的 `website` 保存推文网址，`annotation` 保存推文正文。视频链接导入被 Eagle 拒绝时会回退为临时下载，再通过 Eagle 本地文件接口导入。
- X 的推文接口和媒体地址由 X 提供，接口标识或页面结构改变时可能需要更新兼容解析。

## 小红书

- 按钮只显示在可见帖子详情 `#noteContainer` 的媒体区域左上角。
- 图文帖仅收集当前帖子媒体区的 `.img-container` 图片，跳过 Live Photo 容器并去重。
- 视频帖按 `masterUrl`、播放器地址和 `og:video` 选择一个视频源，依次偏好 `_114.mp4`、`_115.mp4`、`_258.mp4`、`_84.mp4`。
- Eagle 的 `website` 字段保存帖子网址，`annotation` 字段保存正文。

## Eagle 设置与注意事项

- Token 保存在扩展本地存储中。
- 可选设置作者标签、正文话题标签和 Eagle 文件夹 ID。
- 每项帖子媒体创建一个 Eagle 项目，共用该帖的网址和正文注释；视频可在链接导入失败后改用 `addFromPath` 本地文件导入。
- Instagram 私有数据接口和小红书页面结构都可能变化。媒体地址不可访问、接口拒绝请求或 Eagle API 未启用时，扩展会显示失败状态。
